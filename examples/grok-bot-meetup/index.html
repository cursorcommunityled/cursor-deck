Security

Per-user isolation

Each person's work runs on its own VM, with hardware-level separation from everyone else. One computer per person; that person's Bots share it.

No access by default

A Bot only reaches the accounts and plugins someone signs it into. Passwords, 2FA, and payments stay with the person.

Always AllowAllow

Human approval gates

Consequential actions wait for approval. Auto Review sits in front of the risky stuff: sends, publishes, spends, deletes, and similar.

Administrative control

Org-wide enable and off, network policy, connector policy, team rules, and computer terminate. Privacy Mode and the admin controls you already run still apply.
